🚗 Sistema de Gestión para Concesionarios

Aplicación para administrar inventario de vehículos, ventas, apartados (reservas), clientes y reportes con gráficos de desempeño.

📌 Descripción

Este repositorio contiene una aplicación diseñada para la gestión integral de un concesionario automotriz. Permite controlar el inventario, registrar ventas, gestionar apartados, generar reportes y visualizar estadísticas clave para la toma de decisiones.
